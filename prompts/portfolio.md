# 모의 포트폴리오 운용 규칙 (세션 A·D 필독)

2026-08-07부터 가상 자본 **1,000,000원**으로 실제 매매를 시뮬레이션한다.
분석→검증 파이프라인은 그대로 두고, 그 판단을 실제 금액이 걸린 매매로 옮긴다.
상태 파일: `data/portfolio.json` (직접 수정 금지, scripts/pilot.py 명령만 사용)

## 자금 규칙

- 종목당 기본 매수 금액: **200,000원** (현금이 부족하면 가능한 만큼, 자동 조정됨)
- 최대 동시 보유: 5종목
- 수수료 0.015%·매도세 0.15%는 스크립트가 자동 반영한다

## 매수 (세션 D가 실행, 18:00)

1. 오늘 신규로 2주 검증에 편입(open-trade)한 종목은 **동시에 포트폴리오에도 매수한다** (당일 종가):
   ```
   echo '{"code":"005930","name":"삼성전자","price":259000,"amount":200000,"reason":"검증 편입 동반 매수"}' | python3 scripts/pilot.py portfolio-buy
   ```
2. 활성 매수 신호(signals.json의 active) 중 미보유 종목이 있으면 그것도 매수한다.
3. **시작일 예외 (8/10 세션 A가 실행):** 포트폴리오가 비어 있으면, 진행 중인 검증 종목
   (paper_trades의 open)을 당일 종가로 각 200,000원씩 매수해 초기화한다.

## 매도 (세션 A가 실행, 16:30)

보유 종목이 다음에 해당하면 **당일 종가로 전량 매도**한다:
- 장중 고가 기준 목표(+7%, 평단가 대비) 도달 → 수익 실현 매도
- 장중 저가 기준 손절(-5%, 평단가 대비) 터치 → 손절 매도
- 해당 종목의 2주 검증이 종료(passed/failed/excluded) 판정됨 → 청산 매도
- **예외(왕복 매매 금지):** 검증 통과(passed)와 동시에 활성 매수 신호가 생성된 종목은
  팔았다가 같은 날 다시 사지 않는다. 목표 +7% 미도달 통과라면 그냥 계속 보유로 전환하고
  (매도·재매수 생략, log에 "신호 전환 보유" 메모만), +7% 도달 매도라면 재매수는
  다음 날 이후 눌림에서만 검토한다.
```
echo '{"code":"005930","price":275000,"reason":"목표 +7% 도달 수익 실현"}' | python3 scripts/pilot.py portfolio-sell
```

## 평가 (세션 A가 매일 실행)

가격 기록 후 보유 종목 종가로 평가액을 기록한다:
```
echo '[{"code":"005930","close":259000}]' | python3 scripts/pilot.py portfolio-value
```
매도/평가가 끝나면 `python3 scripts/pilot.py portfolio-status`로 상태를 요약에 포함한다.

## 원칙

- 이것은 가상 자본이다. 그러나 실제 돈처럼 다룬다 — 근거 없는 매매 금지, 모든 매매에 reason 기록.
- 가격을 확보하지 못한 종목은 매매하지 않는다 (추측 가격 매매 절대 금지).
- 8/10~8/14 첫 주가 끝나면 주간 성과를 평가받는다. 거래를 위한 거래는 하지 않는다.
